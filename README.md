# OSINT store

A responsive OSINT product store with the slogan "تعلم جمع المعلومات بالطريقة الاستخباراتية", secure administrator access, and a clean catalog containing product name, description, and price. Product changes appear on the public storefront through shared query invalidation and live updates. Orders open WhatsApp directly with the message "مرحبا أريد طلب [Product Name]".
